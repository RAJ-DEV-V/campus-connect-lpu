# Campus Connect LPU – Study Material Hub 🎓

> **“Your centralized hub for LPU study materials.”**  
> Scalable, mobile-friendly academic portal built for 2,000+ Lovely Professional University students.

---

## 🌟 Key Features

1. **Year-Wise Study Library**:
   - Structured strictly: **Year → Subject → Material Type → File**
   - **1st Year** (Freshmen Foundation: Programming in C, Maths-I, Physics, Python)
   - **2nd Year** (Core Department: Data Structures, C++ OOP, Operating Systems, DBMS)
   - **3rd Year** (Specialization: Theory of Computation, Algorithms, AI/ML, Compiler Design)
   - **4th Year** (Capstone & Placements: Deep Learning, Big Data, Distributed Systems)

2. **Core Academic Material Types**:
   - 📚 **Notes** (Unit-by-unit theory, slides, handwritten notes)
   - 📝 **Mid-Term Papers** (Official past mid-term solved questions & marking rubrics)
   - 📕 **End-Term Papers** (Previous end-term papers with numerical solutions)
   - 📄 **PYQs** (High-yield recurring previous year questions)

3. **Mandatory Community Joining Flow**:
   - **Step 1: Landing Page** → Modern university portal feel with live counters.
   - **Step 2: Google Sign-In** → Zero-friction login with Google OAuth or instant test profiles.
   - **Step 3: Community Verification** → Honest, modular verification system connecting students to the WhatsApp/Telegram group.
   - **Step 4: Full Library Unlock** → Instant access with 1-click downloads.

4. **1-Click Direct Downloads & In-Browser Preview**:
   - Downloads start immediately with verified attachment headers.
   - Live download count increment and download history tracking.
   - In-browser PDF preview reader modal.

5. **Secure Admin Dashboard with Active Users Telemetry**:
   - 👥 **Total Users**
   - 🟢 **Active Users** (Students active in the past 30 days)
   - 🟢 **Active Today** (Students active in the past 24 hours)
   - 🟢 **Active This Week** (Students active in the past 7 days)
   - 🟢 **Community Confirmed Users**
   - **User Activity Table**: `| User | Email | Community Status | Last Active |`
   - **Year-Wise Material Upload**: Add notes, mid-terms, end-terms, and PYQs with cloud or local file storage.
   - **Manage Materials**: Edit, delete, view download metrics.

## 🚀 Quick Start

### 1. Run in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).

### 2. Run in Production Mode
```bash
npm run build
npm start
```

### 3. Run Automated End-to-End Test Suite
```bash
node scripts/test-e2e.mjs
```
